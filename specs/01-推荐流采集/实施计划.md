## 3. 模块设计

### 3.1 `utils/topic_classifier.py`

```python
class TopicClassifier:
    def __init__(self, base_url, model, api_key,
                 themes, threshold=0.8, timeout=180)
    def classify(self, items) -> dict[str, list[dict]]
        # items: [{'i':1,'t':'desc...','g':['tag1']}]
        # 返回: {'aweme_id': [{'name':'AI技术','conf':0.95}]}
```

**要点**：
- 内置 `DEFAULT_THEMES`（AI技术 / 艺术 / 读书），含描述与反例
- `temperature=0`，强制 JSON 输出
- 只读 `content`，忽略 `reasoning_content`
- JSON 解析失败重试 1 次，再失败抛 `ClassifierError`
- Key 缺失 → 构造时直接抛错，不静默降级

### 3.2 `utils/feed_store.py`

SQLite 三张表：

```sql
CREATE TABLE IF NOT EXISTS aweme (
    aweme_id     TEXT PRIMARY KEY,
    desc         TEXT,
    author_name  TEXT,
    author_uid   TEXT,
    digg_count   INTEGER,
    comment_count INTEGER,
    create_time  INTEGER,
    topics       TEXT,           -- JSON: [{"name":"读书","conf":0.95}]
    collected    INTEGER DEFAULT 0,  -- 1=已下载视频
    fetched_at   INTEGER
);
CREATE TABLE IF NOT EXISTS comment (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    aweme_id   TEXT NOT NULL,
    comment_id TEXT,
    text       TEXT,
    user_name  TEXT,
    digg_count INTEGER,
    is_reply   INTEGER DEFAULT 0,
    parent_id  TEXT,
    created_at INTEGER,
    UNIQUE(aweme_id, comment_id)
);
CREATE INDEX IF NOT EXISTS idx_comment_aweme ON comment(aweme_id);
```

**方法**：
- `is_seen(aweme_id) -> bool`
- `save_aweme(meta)` / `mark_collected(aweme_id)`
- `save_comments(aweme_id, comments)`
- `stats() -> dict`

### 3.3 `feed_crawler.py`

主流程：

```
main()
 ├─ 加载 .env、初始化 auth / DB / classifier
 ├─ Round 开始，写日志
 ├─ [1] 抓取：refresh_index 1..10 调 get_tab_feed
 │      → 按 aweme_id 去重 → 过滤已入库的
 ├─ [2] 预过滤：desc 空且无标签的丢弃
 ├─ [3] 判定：分批（每批 20 条）调 classifier
 ├─ [4] 分流：conf ≥ 0.8 进下载队列，其余只存元数据
 ├─ [5] 采集：截断到 20 条
 │      ├─ 下载视频（download_work）
 │      ├─ 抓评论（get_work_all_comment）
 │      └─ 落库
 ├─ [6] 写统计日志
 └─ 异常：捕获 → 记日志 → 退出码 1
```

**CLI**：
```bash
python feed_crawler.py                 # 正常跑一轮
python feed_crawler.py --dry-run       # 只抓+判定，不下载
python feed_crawler.py --max-download 5
python feed_crawler.py --threshold 0.9
python feed_crawler.py --stats         # 只打印库统计
```

## 6. 风险与兜底

| 风险 | 兜底 |
|---|---|
| 大模型 API 不可用 | 本轮不下载任何视频，记日志，退出码 1 |
| 抖音限频 `error_code=7` | 放弃本轮，**不重试** |
| 视频直链过期 | 抓到即下，不攒批 |
| 单轮超时（>1h） | 达到 `max-download` 或超时即停，下一轮照常 |
| Token 成本失控 | `max-download` 与 `refresh_index` 次数双重限制 |

**成本上限**：刷 10 屏 × 约 4 条 = 约 40 条/轮，判定约 8k tokens，每月约 570 万 tokens。
