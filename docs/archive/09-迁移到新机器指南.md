# 09 · 迁移到新机器指南

> 记录时间：2026-10-28
> 目的：在另一台电脑 / 另一套网络上继续验证写接口

---

## 1. 重要前提：凭证不能跨机器复制

**`.env` 绝对不能从这台机器复制到另一台**，原因：

| 素材 | 为什么不能跨机 |
|---|---|
| `DY_COOKIES` | 与设备指纹（`ttwid` / `odin_tt`）绑定，换机器会触发风控 |
| `DY_PRIVATE_KEY` | 是浏览器在本机生成的 P-256 密钥 |
| `DY_TICKET` / `DY_TS_SIGN` | 签发给那把本机私钥，换机器后 `ticket_matches_session()` 会失败 |
| `DY_DTRAIT_BLOB` | 设备特征指纹 |

**必须在新机器上重新登录、重新提取。**

## 2. 迁移步骤

### 2.1 拉取代码

```bash
git clone <你的仓库地址> Douyin_Spider
cd Douyin_Spider
```

**注意**：`docs/` 目录在 `ReverseProjects/` 下，不在 `Douyin_Spider` 仓库内。需要单独同步（见第 4 节）。

### 2.2 安装依赖

```bash
# 排除 protobuf / blackboxprotobuf（版本冲突，见 01-环境搭建.md）
grep -v -E '^(protobuf|blackboxprotobuf)' requirements.txt | grep -v '^#' | grep -v '^$' > req_rest.txt
pip install -r req_rest.txt

pip install 'protobuf>=5.27,<6'
pip install --no-deps blackboxprotobuf
```

Windows 用户注意：`grep` 可能不可用，用 PowerShell：

```powershell
Get-Content requirements.txt |
  Where-Object { $_ -notmatch '^(protobuf|blackboxprotobuf)' -and $_ -notmatch '^#' -and $_.Trim() } |
  Set-Content req_rest.txt
pip install -r req_rest.txt
```

### 2.3 验证环境

```bash
python -c "import main; print('imports OK')"
```

如果报循环导入错误，说明导入顺序问题（见 01-环境搭建.md 第 5 节）。

### 2.4 在浏览器登录

**用 Edge 或 Chrome 打开 https://www.douyin.com/ 并登录。**

**关键**：登录后随便点个赞再取消，触发 `ticket` 下发。

### 2.5 完全退出浏览器

```powershell
# 必须完全退出，否则 Cookies 库被独占锁
Stop-Process -Name msedge, chrome -Force -ErrorAction SilentlyContinue
```

### 2.6 提取凭证

```bash
python browser_credential.py --list       # 先看有哪些 profile
python browser_credential.py --dry-run    # 试提取
python browser_credential.py              # 正式写入 .env
```

**成功标志**：

```
素材 4 项, cookie 60+ 个
  私钥        xxxx...
  推导公钥    xxxx...
  公钥验证    通过          ← 必须通过
  ticket      hash.xxx...
  ts_sign     ts.2.xxx...
  client_cert pub.xxx...
  cookie      63 个
    sessionid                有
    UIFID                    有
    ttwid                    有
```

### 2.7 关键验证：profile/self

**这是判断环境是否正常的唯一可靠判据。**

```bash
python -c "
import dy_apis.douyin_api
from utils.common_util import load_env
import utils.http_client as rq
a = load_env()
print('ticket_match:', a.ticket_matches_session())
r = rq.get('https://www.douyin.com/aweme/v1/web/user/profile/self/',
           cookies=a.cookie, verify=False)
print(r.status_code, r.content[:300])
"
```

## 3. 判据表

| profile/self 返回 | 含义 | 下一步 |
|---|---|---|
| `user` 有内容 | ✅ 环境正常 | 可以测写接口 |
| `status_msg: blocked` | ❌ 环境/账号被标记 | 换全新账号，或等解封 |
| `用户未登录` | ❌ cookie 无效 | 重新登录 |
| HTTP 403 | ❌ 风控 | 检查签名或降低频率 |

### 写接口测试（仅当 profile/self 正常）

```bash
# 点赞（可逆，测完立即取消）
python -c "
import dy_apis.douyin_api as api
from utils.common_util import load_env

AID = '7686857842418126114'

import time; time.sleep(2)
print('取消:', api.DouyinAPI.digg(a, AID, '0'))
"
```

## 4. 同步 docs 目录

`docs/` 不在 `Douyin_Spider` 仓库内。三种方式：

### 方式 A：单独建仓库（推荐）

```bash
cd ReverseProjects
git init docs-repo   # 或把 docs 放进已有笔记仓库
```

### 方式 B：把 docs 移进 Douyin_Spider（会污染上游仓库）

```bash
mv docs Douyin_Spider/docs
```

**缺点**：上游仓库是 `cv-cat/Douyin_Spider`，加自己的文档会让 fork 变脏。

### 方式 C：手动复制

直接把 `docs/` 文件夹拷过去（U 盘 / 网盘 / 局域网共享）。

## 6. 已知问题清单（迁移时注意）

| 问题 | 现象 | 解决 |
|---|---|---|
| protobuf 冲突 | `ResolutionImpossible` | 分三步装（见 2.2） |
| 循环导入 | `cannot import name 'DouyinAuth'` | 先 `import dy_apis.douyin_api` |
| GBK 编码 | 二维码渲染失败 | 设 `PYTHONIOENCODING=utf-8` |
| Cookies 被锁 | `WinError 32` | 完全退出浏览器 |
| cookie 32 字节乱码 | 解密值带乱码前缀 | 已在 `browser_credential.py` 处理 |
| Edge 数据目录异常 | profile 不更新 | 检查 `Edge Internal\User Data` |
| 8 个测试失败 | `test_live_pk_ws` 等 | 上游既有问题，不影响主流程 |

## 7. 新机器上如果 profile/self 正常

说明 **blocked 是原机器的 IP / 设备问题**，那么可以继续：

1. 测点赞（可逆）
2. 测收藏（可逆）
3. 测发评论（不可逆，谨慎）
4. 测创作者中心发布（需额外 `x-secsdk-csrf-token` + `dtrait`，见 [06](06-文章核对-发文风控参数.md)）

记得每步之间留间隔，避免触发限频。
