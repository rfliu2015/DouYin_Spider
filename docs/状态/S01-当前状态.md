## 4. 已知风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 写接口失败会作废 ticket | 连带读能力中断 | 生产环境别碰写接口 |
| Edge / Chrome 启用 App-Bound | 凭证提取通道收窄 | 保留 360 极速，或手工从 DevTools 复制 cookie |
| 限频 `error_code=7` | 服务端冷却 | 停止重试，实测间隔 3 天仍触发 |
| **评论接口限频**（2026-10-31 新增） | 大评论量作品只能采到部分 | 回复侧 0.5~2s 随机延迟、失败指数回退（2→4→8→16s）、连续 5 次才中止；一级评论自控翻页 `count=20` + 1.0s 间隔；回复筛选 `REPLY_TOP_PCT=0.45` + `REPLY_BUDGET=35`。见 [工具手册](../主题/T07-工具手册.md) §1.2 |
| **人机验证 `bdturing slide`**（2026-10-31 新增） | 报此错时等待无效，继续重试会加重账号风险等级 | 先探测一次（可能已自行过期）；仍报错则**停手**，需浏览器手动过滑块或换 IP/账号。判据见 [工具手册](../主题/T07-工具手册.md) §1.2 |
| **评论接口限频（IP 级，间歇）**（2026-10-31 实测） | 触发点随累计消耗下降：预算 100 时第 42 次、预算 35 时第 16 次；**换账号无效** | `REPLY_BUDGET=35` 只能少发请求，**不是解决方案**。稳定采集需换 IP（`dy_apis` 支持 proxies，`feed_crawler` 未接入） |
| **大评论量作品采不全** | 约 4600 条评论的作品实测仅 33% | **无解，需断点续抓（未实现）** |
| 依赖装在共用 WinPython | 升级 protobuf 影响其他项目 | 回滚命令见 [环境搭建](../主题/T01-环境搭建.md) §4 |
