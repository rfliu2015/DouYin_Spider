## 3. 用户主页：`get_user_info` 的来龙去脉

> ⚠️ **历史文档里 0/8、6/8、7/8 三个数字并存，这里是澄清。**

### 3.1 时间线

| 阶段 | 结果 | 原因 |
|---|---|---|
| 仅贴 cookie | **0/8** | 缺 `bd-ticket-guard` 素材 |
| 注入 ticket + 私钥 | **6/8 → 7/8** | 补上了签名能力（不同批次测得） |
| 2026-10-29 复测 | **2/2** | 当前状态：**可用** |

**结论：`get_user_info` 现在可用，前提是注入了 ticket / 私钥。**

### 3.2 为什么它对签名更敏感

三个读接口的校验强度不同：

| 接口 | 校验强度 | 缺 ticket 时 |
|---|---|---|
| `aweme/detail` | 低 | ✅ 仍成功 |
| `comment/list` | 低 | ✅ 仍成功（调了 `with_bd_readonly`，但阈值低） |
| `user/profile/other` | **高** | ❌ 失败 |

**根因**：浏览器在 `user/profile/other` 上**带 `bd-ticket-guard` 全套**（2026-08-16 实录 `headers_wire` 确认），而其他两个接口阈值低，不带也能过。

### 3.3 排查过的方向（已排除）

| 假设 | 结论 |
|---|---|
| 请求参数缺失 | ❌ |
| `sec_user_id` 无效 | ❌ |
| `msToken` 过期 | ❌（同一 token 下作品详情全成功） |
| `a_bogus` 时间戳过期 | ❌ |
| 缺 secsdk 签名 | ❌ |
| **缺 `bd-ticket-guard` 素材** | ✅ **根因** |

### 3.4 替代方案

如果暂时没有 ticket，可以**跳过用户主页接口**，改用作品详情里自带的 `author` 字段：

```python
detail = get_work_info(auth, url)['aweme_detail']
author = detail['author']   # 含 nickname / sec_uid / avatar 等
```

## 5. 手工探针的坑

自己拼 request 打读接口时，**必须走项目的签名栈**，否则会踩：

```
HTTP 403  Blocked by ArgusSecurityPlugin Signature Not Found
```

**正确方式**：

```python
import dy_apis.douyin_api  # 必须第一行，规避循环导入
from utils.common_util import load_env
from builder.header import HeaderBuilder, HeaderType
from builder.params import Params
import utils.http_client as rq

a = load_env()
headers = HeaderBuilder.build(HeaderType.GET)
headers.with_bd_readonly(a)
headers.with_csrf(a.cookie_str)
headers.with_uifid(a)
headers.set_header('referer', 'https://www.douyin.com/')

p = Params()
p.with_platform(round_trip_time='0')
p.with_web_id(a, 'https://www.douyin.com/')
p.with_uifid(a)
p.with_verify_fp(a)
p.add_param('msToken', a.msToken)
# 若接口在 PROTECTED_PATHS_GET 里，还需：
# url = p.sign(base_url, uifid=...)
p.with_a_bogus()

r = rq.get(url, params=p.get(), headers=headers.get(), cookies=a.cookie, verify=False)
```

> 项目封装的 `get_work_info` 等已处理好这些，**优先用封装**。

## 7. 限频

| 现象 | 含义 | 处理 |
|---|---|---|
| `error_code=7` | 服务端冷却 | **停止，等待**。实测间隔 3 天仍会触发 |
| `status_code=8 用户未登录` | 会话失效 | 检查 ticket 是否被作废 |
| HTTP 403 `ArgusSecurityPlugin` | 缺 secsdk 签名 | 走 `sign_url()` |

> **反复重试会加重限频。**
