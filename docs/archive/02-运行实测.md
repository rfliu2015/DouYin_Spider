## 1. 凭证准备

### 为什么用 cookie 而不是扫码

README 明确说明 cookie 是**推荐方式**：

> 现在推荐只配置 `DY_COOKIES`：主站 `Auth` 会被作品接口、直播 REST/WebSocket 和创作者中心共同复用。

扫码登录被 fpk1 卡住（详见 [03-扫码登录攻坚.md](03-扫码登录攻坚.md)），因此改用 cookie 验证。

### 写入的凭证

```
cookie 项数  : 64
字符串长度   : 7953 字符
关键字段     : sessionid(32) / sessionid_ss(32) / sid_tt(32)
               UIFID(384) / ttwid(127) / odin_tt(160)
```

### 加载后的 auth 状态

```
uid         = None          ← 未从 cookie 解析出来
cookie 数   = 68            ← 加载时新增了 4 个
ticket      = 无
private_key = 无
ts_sign     = 无
sessionid   = 有
```

**关键观察**：`ticket` / `private_key` / `ts_sign` 全为空。这不是配置遗漏，而是**架构决定的**——cookie 是浏览器登录的产物，而私钥存在浏览器 localStorage 里，不会跟 cookie 一起复制过来。

## 3. 接口成功率实测

同一会话、同一 cookie、同一签名栈，每个接口各测 8 次：

| 接口 | 成功率 | 说明 |
|---|---|---|
| 作品详情 `aweme/detail` | **8/8** | 稳定 |
| 一级评论 `comment/list` | **8/8** | 稳定 |
| 作品列表 `aweme/post` | **8/8** | 稳定 |
| **用户主页 `user/profile/other`** | **0/8** | **100% 失败** |

### 这个分布说明什么

不是风控随机波动——相邻接口全部 8/8 成功，只有这一个 0/8。

不是签名算错——用的是同一套 `Params` / `a_bogus` / `msToken`。

**是接口本身需要的校验机制不同。** 详见 [04-get_user_info诊断.md](04-get_user_info诊断.md)。

## 4. 免登录能力实测

### 直播信息接口：完全不需要账号

```python
import dy_apis.douyin_api as api   # 必须先导入，避开循环导入
import builder.auth as ba

auth = ba.DouyinAuth()             # 空 auth，无任何 cookie
room_info, _ = api.DouyinAPI.get_live_info(auth, "359765653648")
```

返回：

```python
{
  'room_id': '7700436536185064218',
  'anchor_id': '87376620793',
  'sec_uid': 'MS4wLjABAAAAIxqz61yKIHUKfZKxaYt-11JEQyCQs8OVll4eTwEKjmw',
  'room_status': 4,

  'ttwid': '1%7C...',
```

### 直播 WebSocket：需要匿名设备 cookie

**裸连接被拒**：

```
WebSocketBadStatusException: Handshake status 200 OK
  handshake-msg: 'http: named cookie not present'
  handshake-status: '417'
```

**补上匿名 `ttwid` 后握手通过**（收到 2 帧），但该房间 `room_status=4`（未开播），无法验证弹幕解析。

### 签名栈：纯 Python 本地可算

```python
from utils.dy_util import generate_a_bogus

generate_a_bogus("device_platform=webapp&aid=6383&aweme_id=...", host="www.douyin.com")
# → 'dy4RgFUyx2/bcdFtmcOrCRalKMgMrP8yvPTdbzoUHxEL...' (len=192)

generate_a_bogus(..., host="live.douyin.com")
# → 'OXs5hwXJENWfOVFS8Cai94CUOzylrB8yvPiObwquexYL...' (len=196)
```

注意不同 host 产出不同（签名内嵌 `(aid, page_id)`）。

```python
from utils.secsdk_web_sign import sign_url, PROTECTED_PATHS_GET
sign_url("https://www.douyin.com/aweme/v1/web/aweme/detail/?aweme_id=...",
         ts=1720000000, uifid="test-uifid")
# → 正常返回带 x-secsdk-web-signature 的完整 URL
```

**这是项目最有价值的部分之一**：secsdk webSign 用 187 行纯 Python 实现了，不需要浏览器。
